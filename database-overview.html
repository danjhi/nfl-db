3. Dynasty Values & Positional Model

Dynasty trade values synced from Google Sheets, change history, future pick values, and a positional adjustment model.

dynasty_values 714 rows

Current dynasty trade values (1QB + Superflex) for every relevant player. Synced from Google Sheet via Apps Script (full delete + insert). All 714 rows have both 1QB and SF values.

PK: player_id FK → players RLS: anon SELECT only

dynasty_value_history 764 rows

Change log of dynasty value adjustments. Each row records an old→new value change with editorial comment.

PK: (player_id, date) FK → players

dynasty_pick_values 32 rows

Future draft pick trade values. 2 years × 4 rounds × 4 tiers (early/mid/late/random). Manually maintained — values change rarely.

PK: (year, round, tier)

positional_model_coefficients 4 rows

Linear model coefficients from R multivariate regression. Predicts positional value share (% of total fantasy points above replacement) given 14 league setting variables. One row per position (QB, RB, WR, TE).

PK: position
Usage: predicted_share = intercept + coef1×x1 + … + coef14×x14, then multiplier = baseline_share / predicted_share.

positional_model_baselines 2 rows

Default positional value shares for 1QB and Superflex formats. When user settings match baseline, all multipliers = 1.0.

PK: format ('1qb' | 'sf')

One row per team per regular-season game (2016–2025). Contains offensive and defensive stats by category, Vegas lines, and positional breakdowns. PPR variants are Postgres generated columns (auto-computed from standard FP + receptions).

10. Views
